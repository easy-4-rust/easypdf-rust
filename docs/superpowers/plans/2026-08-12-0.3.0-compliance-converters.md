# v0.3.0 合规与转换器 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: rust-testing, rust-code-review

**Goal:** 实现 PDF/A-1b/2b/3b 完整校验、XMP 元数据生成、SVG→PDF 转换、PDF→image 光栅化、Markdown→PDF 优化，使 easypdf-rust 达到合规和转换器的生产级能力。

**Architecture:** 延续 9-crate 架构。新增功能主要影响 easypdf-reader（PDF/A 校验）、easypdf-core（XMP 元数据）、easypdf-writer（SVG→PDF）、easypdf-markdown（Markdown→PDF 优化）。

**Tech Stack:** Rust 1.88+, quick-xml（XMP XML）, svg2pdf / printpdf（SVG）

## Global Constraints

- 保持 `#![deny(unsafe_code)]` 策略。
- 不破坏现有 1700+ 测试。
- PDF/A 校验通过标准测试用例。
- PDF→image 输出可被标准图片查看器打开。
