# easypdf-rust v0.4+ Rich Content Next -- Future Implementation Roadmap

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 v0.1.0 发布后剩余的功能：0.3 Rich Content 剩余 5 项、0.4 OCR 端到端集成、0.5 Compliance（PDF/A + XMP）、0.6 Converters 剩余（SVG→PDF / PDF→image）、1.0 Stable 门禁。

**Architecture:** 延续 9-crate 架构。新增功能主要影响 easypdf-writer（图片/形状/字体增强）、easypdf-markdown（OCR 端到端）、easypdf-reader（SVG→PDF / PDF→image）、easypdf-core（XMP 元数据）。

**Tech Stack:** 待定（取决于具体实现方案，参见各功能描述）。

## Global Constraints

- 每个功能必须有独立测试，不依赖外部服务（OCR 真实集成除外）。
- 保持 `#![deny(unsafe_code)]` 策略。
- 不破坏现有公共 API 兼容性。
- 新增 feature gate 控制可选功能。
