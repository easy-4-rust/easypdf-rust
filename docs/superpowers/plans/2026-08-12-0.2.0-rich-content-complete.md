# v0.2.0 Rich Content 完整覆盖 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: rust-testing, rust-performance

**Goal:** 补齐 0.3 Rich Content 剩余 5 项（表格边框增强、图片插入增强、矢量图形增强、自定义字体增强、多页自动分页），使 PDF 写入能力达到生产级。

**Architecture:** 延续 9-crate 架构。主要修改 `easypdf-writer`（图片/形状/字体/布局增强）和 `easypdf-core`（布局引擎扩展）。

**Tech Stack:** printpdf 0.8, Rust 1.88+, criterion（benchmark）

## Global Constraints

- 保持 `#![deny(unsafe_code)]` 策略。
- 不破坏现有 1522 测试。
- 每个功能有独立测试。

## 关键发现（代码核对）

- `add_table` 基础已实现（`crates/easypdf/src/builders.rs:95`），但斑马纹/合并单元格/自定义边框未实现。
- `write_image` 基础已实现（`crates/easypdf-writer/src/image.rs:15`），但缩放/定位/旋转增强未实现。
- `draw_line/rect/circle` 基础已实现（`crates/easypdf-writer/src/shape.rs`），但填充/椭圆/多边形/路径未实现。
- `register_font_from_path/bytes` 已实现（`crates/easypdf-writer/src/writer.rs:196-202`），但缓存/度量未实现。
- FlowLayout 基础已实现（`crates/easypdf-core/src/layout.rs`），但自动分页/跨页拆分未实现。
- SVG→PDF 未找到实现（`Svg::parse` 或 `add_svg` 调用）。
- XMP 生成未找到实现。
- OCR 引擎已就绪（4 个），但 Markdown 转换中的图片 OCR 集成未端到端接通。
