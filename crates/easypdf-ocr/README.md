# easypdf-ocr

Cloud OCR engine collection for [easypdf-rust](https://github.com/easy-4-rust/easypdf-rust).

This crate is part of the `easypdf` workspace. See the
[root README](https://github.com/easy-4-rust/easypdf-rust/blob/main/README.md)
for full documentation.

## Included engines

- **GLM-OCR** -- Zhipu BigModel
- **HunyuanOCR** -- Tencent Cloud
- **Baidu Qianfan / PP-OCRv6**
- **DeepSeek-OCR-2** (via LLM)
