# easypdf-runtime

Runtime layer for [easypdf-rust](https://github.com/easy-4-rust/easypdf-rust):
MCP server and resident daemon.

This crate is part of the `easypdf` workspace. See the
[root README](https://github.com/easy-4-rust/easypdf-rust/blob/main/README.md)
for full documentation.

## Features

- **mcp** -- Model Context Protocol server (`easypdf-mcp` binary)
- **resident** -- Resident daemon mode
