# Sample PDFs for parity testing

All sample PDFs in this directory are **generated by `easypdf-rust` itself**
using the `generate_golden` helper binary. They are therefore Apache-2.0
licensed (same as the project).

Each sample is intentionally small (< 10 KB) so it can safely be committed
to git.

## Samples

| File | Description | Pages |
|------|-------------|-------|
| `minimal.pdf` | Single page with "Hello World" text | 1 |
| `multipage.pdf` | Three pages with "Page 1", "Page 2", "Page 3" | 3 |
| `with-metadata.pdf` | Single page with Title and Author metadata | 1 |

## How to regenerate

```bash
cargo run -p easypdf-parity --bin generate_samples
```

This will overwrite existing samples. Review the diff before committing.
